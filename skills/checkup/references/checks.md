# 주기별 점검 항목

상위 주기는 하위 주기 항목을 포함한다. **자동** = `ops-check.sh`, **AI** = checkup 스킬, **사람** = 보고서 TODO.

## daily (매일)
| 항목 | 방식 | 기준 |
|---|---|---|
| 헬스체크 | 자동 | 2xx, 응답 3초 이내 |
| TLS 인증서 | 자동 | 만료 14일 전 경고 |
| 만료일 목록 | 자동 | 30일 전 경고 |
| 방문 기록이 들어오는가 | AI (지표 화면·본부 숫자) | 어제 `landing` 0건인데 핵심 행동은 있으면 WARN (측정이 끊김) |
| 에러 급증·신규 오류 | 모니터링 도구 알림 (operate O1) | — |
| 새 문의 | 사람 | 응답 기준 (operate O4) |

## weekly (월요일)
| 항목 | 방식 | 기준 |
|---|---|---|
| 의존성 취약점 | 자동 | 높음 이상 0 |
| 백업 신선도 | 자동 (`BACKUP_CHECK_CMD`) | 최근 백업 존재 |
| 지난주 배포·변경 요약 | AI | — |
| 실패 워크플로 | AI | 반복 실패는 WARN |
| 새 버그·열린 알림 이슈 | AI | 1주 넘게 열린 치명 이슈는 FAIL |
| 지표 추세 (`docs/growth.md`) | AI | 핵심 지표 2주 연속 하락은 WARN |
| 문의 태그 요약 → grow | AI + 사람 | — |

## monthly (매월 1일)
| 항목 | 방식 |
|---|---|
| 비용 점검, 사용자당 비용 갱신, **무료 한도 사용률(70% 경고)** | 사람 (AI 가 표 준비) |
| 의존성 업데이트 | AI 가 목록·위험도 정리, 사람이 기능 사이클로 진행 |
| 런타임·SDK 지원 종료 일정 | AI (공식 문서 확인) |
| 사후 분석 재발 방지 조치 완료 여부 | AI |

## quarterly (1·4·7·10월 1일)
| 항목 | 방식 |
|---|---|
| 백업 복구 실습 | 사람 (절차: operate `backup-recovery.md`) |
| 런북 갱신 | AI 초안, 사람 확인 |
| 스토어·법·플랫폼 정책 변경 | AI (공식 출처 확인), 사람 판단 |
| 공식 출처 링크 점검: Atelier 산출물(`docs/guard.md`·`docs/growth.md` 등)에 적힌 공식 링크가 살아 있는지, "확인일"이 6개월 넘은 기준(심사·세금·AI 고지 등)은 다시 확인해 날짜 갱신 | AI |
| 보유 기간 지난 데이터 파기 | 사람 |
| 개발자 계정·결제 수단 갱신 | 사람 |
| 세금 신고 달력: 이번 분기·다음 분기에 다가오는 신고(부가세·종합소득세 등), 지난 분기 해외 결제 영수증·외화 입금 명세 모음 (`docs/guard.md` "세금" 표, 수익이 있을 때만) | AI 가 기한·빠진 증빙 목록, 사람이 신고 (`../../guard/references/tax-kr.md`) |
