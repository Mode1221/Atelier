# 수익화·가격

## 과금 기준 (가치 지표)
사용자가 얻는 가치와 함께 늘어나는 단위로 과금한다: 프로젝트 수, 사용량, 좌석, 고급 기능.

## 무료 / 유료 경계
- 무료로 **핵심 가치를 경험**할 수 있어야 한다 (aha 는 무료)
- 유료는 더 많이·더 편하게·함께: 한도 확대, 고급 기능, 협업, 광고 제거
- 비용이 드는 기능(LLM·API)은 무료 한도를 둔다 (idea I5 공헌이익)

## 가격 정하기
- 경쟁·대안 가격(idea I2), 사용자가 지금 쓰는 돈·시간
- 요금제 2~3개, 연간 할인
- 처음엔 **조금 높게**: 올리기보다 내리기(할인)가 쉽다
- 가격 인터뷰: "이 가격이면 너무 싸서 의심된다 / 싸다 / 비싸다 / 너무 비싸서 안 산다" (Van Westendorp)

## 가격 변경
- 기존 유료 사용자는 기존 가격 유지 기간(grandfathering) 검토
- 인상은 미리 고지 (약관·스토어 정책 확인)

## 광고 (광고 모델이면)
- 핵심 흐름을 방해하지 않는 위치
- 보상형 광고(게임)는 사용자 선택
- 광고 SDK 수집 항목 → 처리방침·스토어 표시·동의(ATT 등) 반영 (guard)
