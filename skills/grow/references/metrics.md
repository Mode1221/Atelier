# 지표

## 북극성 지표
사용자가 얻는 핵심 가치를 가장 잘 나타내는 숫자 **하나**.
- 예: 주간 완성된 코스 수, 주간 활성 편집자 수, 주간 플레이 세션 수
- 조건: 사용자 가치와 연결, 매출을 선행, 팀(나)이 움직일 수 있음

## 대시보드 구성
| 영역 | 지표 |
|---|---|
| 획득 | 채널별 방문·가입, 가입 전환율, (유료 광고 시) 채널별 **CAC**(광고비 ÷ 핵심 행동까지 간 사람) |
| 활성화 | 가입 → 첫 핵심 행동 비율, 걸린 시간 |
| 유지 | D1·D7·D30 리텐션, 주간 활성 사용자(WAU), DAU/MAU |
| 수익 | 유료 전환율, MRR, ARPU, 해지율(churn), 환불률, **LTV**(사용자당 월 공헌이익 × 평균 유지 개월), **회수 기간**(CAC ÷ 월 공헌이익) — 계산법은 `paid-acquisition.md` |
| 추천 | 공유·초대 수, 초대로 온 가입 |
| 품질 | 오류율, 크래시 없는 사용자 비율, p95 응답 시간 |
| 비용 | 사용자당 비용, 공헌이익률 |

## 참고 기준
업종·장르별 편차가 크다. 절대 기준보다 **자기 추세**와 비슷한 제품 공개 자료를 비교한다.

## 원칙
- 매주 같은 요일에 스냅숏 기록 → 추세를 본다
- 숫자가 변하면 "왜?"를 적는다 (배포·홍보·계절)
