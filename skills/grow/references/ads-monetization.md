# 광고 수익 (애드센스·애드핏·AdMob)

**idea I5 에서 수익 경로가 "광고"일 때만** 쓴다. 광고는 승인부터 받아야 붙고, 승인 전에 할 일이 꽤 있다.
기준·기간은 자주 바뀐다. 아래는 **2026-10-01 확인** 기준의 흐름이고, 실행할 때마다 공식 도움말에서 다시 확인해 확인일을 `docs/growth.md` 에 적는다.

## 먼저 계산: 광고를 붙일 만한가
`(월 페이지뷰) × (페이지당 광고 노출) × (노출 1,000회당 수익) ÷ 1,000`
- 노출 1,000회당 수익은 분야·국가·광고 위치에 따라 크게 다르다. 숫자를 지어내지 말고 **범위로**(낮게 잡은 값·높게 잡은 값) 계산하고, 출처가 없으면 "추정"이라고 쓴다.
- 결과가 월 서버비·도메인비보다 작으면 광고보다 사용자 경험을 지키는 쪽이 낫다는 것도 선택지다(대표에게 둘 다 보여 준다).
- 광고는 화면을 차지하고 느리게 만든다 — 핵심 행동 흐름(가입·결제·작성) 화면에는 넣지 않는다.

## 웹: 구글 애드센스
공식: [애드센스 도움말](https://support.google.com/adsense) · [가입 자격](https://support.google.com/adsense/answer/9724) · [사이트 페이지 준비](https://support.google.com/adsense/answer/7299563) · [ads.txt](https://support.google.com/adsense/answer/12171612) · [게시자 정책](https://support.google.com/adsense/answer/10502938)
**2단계**: 계정 승인(본인·지급 정보) → **사이트 승인**(사이트를 직접 검토). 보통 며칠에서 2~4주, 그 이상도 있다.

### 승인 전 체크리스트 (AI 가 확인하고 결과를 `docs/growth.md` 에)
- [ ] **내 도메인**(자체 도메인)으로 운영 — 무료 하위 주소(`*.workers.dev` 등)는 사이트 추가가 안 되거나 거절되기 쉽다 → `../../build/references/domain.md`
- [ ] 직접 쓴 **콘텐츠가 충분**하다 — 도구형 서비스(빈 입력 화면만 있는 사이트)는 "가치가 낮은 콘텐츠"로 거절되기 쉽다. 사용법·사례·자주 묻는 질문 같은 읽을 거리 페이지를 둔다. AI 로 대량 생성한 글은 거절 사유가 된다
- [ ] **탐색이 쉽다** — 첫 화면에서 메뉴·주요 페이지로 갈 수 있고, 깨진 링크·"준비 중" 페이지가 없다
- [ ] **정책 페이지**: 개인정보처리방침(광고 쿠키·맞춤 광고와 거부 방법 포함 — `../../guard/references/legal-docs-outline.md` 11번), 소개, 연락처
- [ ] 사이트가 승인 기간 내내 열려 있다(검토 중에 주소를 바꾸지 않는다)
- [ ] 금지 콘텐츠·저작권 침해 없음, 클릭 유도 문구 없음("광고를 눌러 주세요" 금지)
- [ ] 승인되면 루트에 `ads.txt`(게시자 ID 한 줄), 광고 코드는 승인 후에만 넣는다
- 흔한 거절: 콘텐츠 부족·가치 낮음 · 탐색 어려움 · 정책 페이지 없음 · 사이트에 접속 안 됨 · 사이트 소유 확인 실패.
- 사람 할 일: 애드센스 가입·지급 정보·세금 정보(해외 지급 — `../../guard/references/tax-kr.md`), 사이트 추가·검토 요청 버튼.

## 웹 대안: 카카오 애드핏
공식: [카카오 애드핏](https://adfit.kakao.com) — 국내 대상 웹·앱. 심사 기준과 지급 조건을 공식 페이지에서 확인한다. 애드센스 승인을 기다리는 동안 또는 거절 뒤 대안으로 검토.

## 앱: AdMob
공식: [AdMob 도움말](https://support.google.com/admob) — 앱이 스토어에 **출시된 뒤** 앱 연결·검토가 끝나야 광고가 제대로 나간다. `app-ads.txt` 를 개발자 웹사이트(스토어에 적은 주소) 루트에 둔다.
- 개발 중에는 반드시 **테스트 광고 ID** 로만(내 광고를 직접 누르면 계정이 정지될 수 있다).
- 스토어 개인정보 표시(데이터 보안 섹션·개인정보 라벨)에 광고 SDK 수집 항목을 넣는다(guard G3 세 곳 일치).

## 붙이기 (승인 뒤)
- 웹: `../../build/templates/ads/ads.js` 를 `public/` 에 — `ADS.client`·`slots` 만 채우면 결제·가입 화면은 빼고 자리를 미리 잡아 붙인다. `/ads.txt` 는 `adsTxt(client)` 결과를 그대로.
- 앱(AdMob): `react-native-google-mobile-ads`, 개발 중엔 테스트 광고 단위 ID 만, 출시 빌드에서만 실제 ID.
