# 온보딩·리텐션

## 활성화 (첫 가치 경험)
- aha moment 정의 = 이걸 한 사용자가 남는다 (R2 코호트 비교로 찾는다)
- 가입 → aha 까지 단계·시간을 줄인다: 가입 뒤로 미루기, 기본값·샘플 데이터, 설정 질문 최소화
- 빈 화면 대신 템플릿·예시

## 습관
- 트리거: 사용자가 이 제품을 떠올리는 상황. 알림은 그 상황에 맞춰(시간·맥락)
- 알림은 **가치 있는 정보**만. 스팸성 알림은 알림 끄기·삭제로 이어진다
- 진행 저장·연속 기록 등은 사용자 가치와 연결될 때만

## 이탈 방지
- 이탈 신호: 활동 감소, 핵심 기능 미사용, 결제 실패
- 대응: 도움말·재참여 메시지(수신 동의 범위), 결제 실패 재시도·안내
- 해지 시 이유를 묻는다 (선택 입력, 해지를 방해하지 않음)

## 이탈 인터뷰
- 떠난 사용자 3~5명에게: "마지막으로 쓴 게 언제고, 그때 무엇을 하려 했나?", "대신 무엇을 쓰나?"
- Mom Test 원칙 (`../../idea/references/validation-checklist.md`)

## 게임
- 첫 5분 이탈 지점(튜토리얼 단계별 완료율)
- 세션 길이·세션 수, 콘텐츠 소진 속도
- 난이도 급상승 구간(실패율 급증 레벨)
