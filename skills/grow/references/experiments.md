# 실험

## 형식
```markdown
### EXP-001 온보딩 샘플 데이터
- 가설: 첫 화면에 샘플 데이터를 넣으면 활성화율이 오른다. 빈 화면에서 무엇을 할지 몰라 이탈하기 때문(인터뷰 3건).
- 지표: 가입 → 첫 핵심 행동 비율 (주), 오류율·해지율 (안전 지표)
- 방법: A/B (50:50) 또는 전후 비교
- 기간·표본: 최소 N 명 또는 2주
- 결과: 
- 결정: 적용 / 폐기 / 재실험
```

## 트래픽이 적을 때 (1인 서비스 대부분)
- A/B 로 작은 차이는 검출이 안 된다. 표본 계산기로 필요한 사용자 수를 먼저 확인
- 대안: 큰 변화만 실험, 전후 비교(같은 요일·기간), 사용성 테스트·인터뷰로 질적 확인
- 한 번에 하나만 바꾼다

## 원칙
- 결과를 보기 전에 기간·지표·판단 기준을 정한다 (중간에 좋아 보일 때 멈추지 않기)
- 실패한 실험도 기록한다 — 다음 가설의 재료
- 기능 플래그로 켜고 끄기 (build B12)
