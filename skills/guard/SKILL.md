# Guard — 보안·법률

## 보안
1. `/security-review` 를 실행한다.
2. 비밀값 노출, 인증·권한, 입력 검증, 의존성 취약점을 점검한다.

## 법률 (초안만 작성, 최종 판단은 전문가)
1. 수집하는 개인정보 항목을 코드에서 찾아 목록화한다.
2. 개인정보처리방침·이용약관 초안을 만든다.
3. 사용한 오픈소스·에셋·폰트의 라이선스를 점검한다.
4. (앱) 스토어 심사 가이드라인 체크리스트를 확인한다.

## 완료 조건
- 치명 보안 이슈 0, 약관·방침 게시, 라이선스 문제 0

> 이 스킬의 법률 산출물은 참고용 초안이다. 결과물에 항상 이 안내를 붙인다.
