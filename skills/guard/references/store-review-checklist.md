# 스토어·플랫폼 심사 체크리스트

자주 거절되는 사유 위주. 정책은 자주 바뀌므로 제출 전 공식 문서 최신본을 확인한다.
- Apple: App Store Review Guidelines
- Google: Play 개발자 정책 센터

## 공통
- [ ] 크래시 없음, 모든 버튼·링크 동작, 임시 문구(Lorem ipsum, TODO) 없음
- [ ] 로그인이 필요하면 **심사용 데모 계정**을 제출 정보에 기재
- [ ] 개인정보처리방침 URL (스토어 등록 정보 + 앱 내부)
- [ ] 스토어 개인정보 표시(Apple App Privacy / Google Data safety)가 실제 수집·SDK 와 일치
- [ ] 계정을 만들 수 있으면 **앱 안에서 계정 삭제** 가능 (Google 은 웹 삭제 요청 경로도 요구)
- [ ] 스크린샷·설명이 실제 기능과 일치, 과장·타사 상표 사용 금지
- [ ] 사용자 생성 콘텐츠가 있으면: 신고·차단·필터링 기능, 운영 정책
- [ ] 연령 등급 설문을 정확히 답변
- [ ] 권한 요청(카메라·위치·알림)은 필요한 순간에, 이유 문구와 함께

## Apple App Store
- [ ] 최소 기능: 웹사이트를 감싼 것뿐인 앱은 거절되기 쉽다 (4.2)
- [ ] 디지털 콘텐츠·구독 판매는 인앱 결제 원칙 (3.1.1). 국가별 예외(한국 대체 결제 등)는 최신 규정 확인
- [ ] 제3자 소셜 로그인만 제공하면 개인정보 보호형 로그인 옵션 요건 확인 (4.8)
- [ ] 개인정보 매니페스트(Privacy Manifest)·사용 이유가 필요한 API 선언
- [ ] 구독: 가격·기간·자동 갱신·해지 방법 표시, 복원(Restore) 버튼
- [ ] 베타 테스트는 TestFlight

## Google Play
- [ ] **대상 API 레벨** 요건 충족 (매년 상향)
- [ ] 2023년 11월 이후 만든 **개인 개발자 계정**은 프로덕션 출시 전 **비공개 테스트**(일정 인원·연속 기간, 현재 12명·14일) 필요 여부 확인
- [ ] 디지털 상품은 Google Play 결제 원칙. 한국 등 사용자 선택 결제 허용 국가 규정 확인
- [ ] 민감 권한(SMS, 통화기록, 전체 파일 접근, 백그라운드 위치)은 별도 신고·사유 필요
- [ ] 앱 서명 키 분실 대비 (Play 앱 서명 사용)

## 게임 추가
- [ ] 유료 확률형 아이템 확률 공개 (한국 법, 스토어 정책 모두)
- [ ] 한국 유통: 등급분류 처리 경로 확인 (`privacy-checklist-kr.md` 게임산업법 항목)
- [ ] Steam: 스토어 페이지·빌드 심사 기간 고려, 출시 전 "Coming Soon" 페이지 최소 공개 기간, AI 콘텐츠 공개 항목
- [ ] 콘솔은 별도 개발자 프로그램·인증 필요

## 웹 서비스
- [ ] 푸터에 처리방침·약관 링크, (유료면) 사업자 정보
- [ ] 쿠키 동의 배너 (EU 사용자 대상이면)
- [ ] 결제 PG 사 가맹 심사 요건 (약관·환불 규정·사업자 정보 게시)

## 사업·업종 신고 (사람이 할 일)
