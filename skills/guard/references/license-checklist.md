# 라이선스 체크리스트

## 오픈소스 코드
| 유형 | 예 | 1인 상용 서비스에서 |
|---|---|---|
| 허용형 | MIT, BSD, Apache-2.0, ISC | 사용 가능. **저작권·라이선스 고지** 필요 (Apache 는 NOTICE 파일도) |
| 약한 카피레프트 | LGPL, MPL-2.0 | 대체로 가능. 해당 라이브러리 수정분 공개 등 조건 확인 |
| 강한 카피레프트 | GPL-2.0/3.0 | 앱·바이너리를 **배포**하면 전체 소스 공개 의무 가능성. 모바일·게임 배포 시 주의 |
| 네트워크 카피레프트 | AGPL-3.0 | 서버에서만 돌려도 사용자에게 소스 제공 의무 가능성. SaaS 에서 특히 주의 |
| 소스 공개·상용 제한 | BSL, SSPL, Elastic, Commons Clause | 조건별 확인. "오픈소스"가 아닐 수 있음 |
| 라이선스 없음 | — | 기본적으로 **사용 권한 없음** |

도구: `npx license-checker --summary`, `pip-licenses`, `flutter pub deps` + 패키지 페이지, Unity/Godot 플러그인은 각 페이지 확인.

## 폰트
- [ ] 상용 사용 허용 여부, 웹 임베드·앱 임베드 허용 여부
- [ ] SIL OFL (예: Pretendard, Noto) → 임베드·상용 가능, 폰트 단독 판매 금지
- [ ] 무료 폰트라도 "개인 무료 / 상업 유료"인 경우가 많다

## 이미지·아이콘·일러스트
- [ ] 출처와 라이선스를 표로 기록 (Unsplash·Pexels 등도 각 약관 확인)
- [ ] 아이콘 세트 라이선스 (Lucide ISC, Material Symbols Apache-2.0 등)와 고지 조건
- [ ] 로고·캐릭터·브랜드 요소 무단 사용 금지 (상표권)

## 음원·효과음 (게임·영상)
- [ ] 상업 사용·재배포(게임 빌드에 포함) 허용 여부
- [ ] CC-BY 는 저작자 표시 필요, CC-NC 는 상업 사용 불가

## 게임 에셋
- [ ] 에셋 스토어 라이선스 범위 (1인/좌석 수, 소스 형태 재배포 금지 등)
- [ ] 모드·팬게임이면 원작 IP 정책 확인

## AI 생성물
- [ ] 사용한 AI 도구의 약관에서 상업적 사용 허용 확인
- [ ] 스토어·플랫폼의 AI 생성 콘텐츠 공개 정책 확인 (예: Steam 은 AI 사용 여부 공개 항목이 있다)
- [ ] 실존 인물·브랜드·타 작품을 모방한 결과물은 쓰지 않는다
