# 개인정보·관련 법 체크리스트 (한국 기준)

> 참고용 요약이다. 조항은 개정될 수 있으니 법제처(law.go.kr)·개인정보보호위원회(pipc.go.kr)에서 최신본을 확인한다.

## 개인정보 보호법
- [ ] **개인정보처리방침** 수립·공개 (앱·웹에서 쉽게 찾을 위치) — 제30조
  - 필수 기재: 처리 목적, 처리하는 항목, 처리·보유 기간, 제3자 제공, 처리 위탁, 국외 이전, 파기 절차·방법,
    정보주체 권리와 행사 방법, 안전성 확보 조치, 자동 수집 장치(쿠키 등) 설치·운영·거부, 개인정보 보호책임자 연락처
- [ ] 수집 시 동의가 필요한 경우 **필수/선택 구분**, 선택 미동의로 서비스 거부 금지
- [ ] 만 14세 미만 대상이면 **법정대리인 동의** 절차 — 제22조의2
- [ ] **처리 위탁**(호스팅, 이메일 발송, 분석 도구 등) 내역 공개
- [ ] **국외 이전**: 해외 클라우드·SaaS(AWS 해외 리전, Vercel, Firebase 등)에 저장하면 이전 국가·업체·항목 등을 처리방침에 공개
- [ ] 목적 달성 시 **파기**, 보유 기간 명시
- [ ] 정보주체의 열람·정정·삭제·처리정지 요청 경로 (회원 탈퇴 = 삭제 경로 포함)
- [ ] **다른 사람이 입력한 개인정보**(예: 모임 운영자가 멤버 이름을 입력)가 있으면, 그 당사자가 열람·삭제를 요청할 경로를 처리방침에 적는다. 별명 사용을 권해 수집 자체를 줄인다
- [ ] 안전성 확보 조치: 접근 권한 최소화, 접속 기록 보관, 암호화(비밀번호·고유식별정보)
- [ ] 유출 시 통지·신고 절차를 알고 있다

## 정보통신망법
- [ ] 광고성 정보(마케팅 푸시·이메일·문자) 전송은 **사전 수신 동의** — 제50조
- [ ] 야간(21시~다음 날 8시) 광고성 전송은 별도 동의
- [ ] 광고 메시지에 "(광고)" 표시와 수신 거부 방법
- [ ] 수신 동의자에게 정기적으로 동의 여부 확인 안내

## 인공지능 기본법 (생성형 AI 기능이 있으면)
정식 이름 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」, **2026-01-22 시행** (2026-10-01 확인). 공식: [법제처 법령](https://www.law.go.kr/법령/인공지능발전과신뢰기반조성등에관한기본법) · [과학기술정보통신부](https://www.msit.go.kr) 고시·가이드라인.
LLM 으로 글·이미지·음성·요약을 만들어 사용자에게 보여 주면 대상이 될 수 있다. 의무 범위·예외·과태료 유예(계도) 기간은 시행령·가이드라인으로 정해지므로 **실행할 때마다 위 공식 출처에서 현재 기준을 확인**하고 확인일을 `docs/guard.md` 에 적는다.
- [ ] **사전 고지**: 이 기능이 생성형 AI 로 동작한다는 사실을 쓰기 전에 알린다 — 기능 화면 안 한 줄(예: "이 추천은 AI 가 만들어요. 틀릴 수 있어요"), 약관·처리방침에도.
- [ ] **결과물 표시**: AI 가 만든 결과물에 그 사실을 표시한다 — 화면에 보이는 표시(배지·문구) 또는 파일·이미지 안의 보이지 않는 표시(메타데이터·워터마크). 밖으로 공유되는 결과물(이미지·공유 링크 미리보기)은 보이는 표시 쪽을 기본으로.
- [ ] **실제와 헷갈리는 결과물**(실존 인물 얼굴·목소리, 사실처럼 보이는 사진)을 만들면 이용자가 분명히 알 수 있게 표시한다. 기능 자체를 넣을지부터 다시 본다.
- [ ] 처리방침: AI 처리 항목(무엇을 AI 에 보내는지), **LLM API 국외 이전**(업체·국가·항목·보유), 입력이 모델 학습에 쓰이는지(업체 약관 확인).
- [ ] 고영향 AI(채용·대출·의료·교육 평가 등 사람에게 중대한 영향을 주는 판단)는 별도 의무가 크다 → 1인 MVP 범위에서 빼거나 전문가 확인.

## 위치정보법 (위치 기능이 있으면)
- [ ] 개인 위치정보를 이용한 서비스 → **위치기반서비스사업 신고** 대상인지 확인 (방송통신위원회)
- [ ] 위치정보 이용약관, 별도 동의

## 전자상거래법 등 (돈을 받으면)
- [ ] **사업자등록**, 온라인 판매 시 **통신판매업 신고**
- [ ] 사이트·앱에 사업자 정보 표시 (상호, 대표자, 주소, 연락처, 사업자등록번호, 통신판매업 신고번호)
- [ ] 청약철회(환불) 규정, 구독이면 자동 갱신·해지 방법 고지
- [ ] 스토어 인앱 결제만 쓰는 경우에도 신고 의무 해당 여부 확인

## 게임산업법 (게임이면)
- [ ] **등급분류**: 자체등급분류사업자로 지정된 오픈마켓(주요 모바일 스토어 등)으로 유통하면 그 절차로 대체. 해당 플랫폼이 지정됐는지 확인하고, 아니면 게임물관리위원회 등급분류
- [ ] 유료 **확률형 아이템**이 있으면 종류·확률 정보 공개 의무
