# 단계별 대표 확인 (3분, 쉬운 말)

게이트를 넘기 전에 대표에게 **직접 보고 누를 것**을 한 줄씩 준다. 대표가 "봤어요"라고 해야 그 항목이 끝난다(자동 모드면 AI 가 캡처로 대신 확인하고 "대표 확인 대기"로 남긴다).
보여 줄 때는 파일 경로보다 **주소·그림**을 준다(`SendUserFile`, 배포 주소).

| 단계 | 대표가 볼 것 | 대표가 답할 것 |
|---|---|---|
| 1 아이디어 | `docs/idea.md` 맨 위 문제 문장 + 경쟁 표 + 이름 상표 검색 결과 | "이 사람의 이 불편이 맞다" / 이름 괜찮은지 |
| 2 기획 | `docs/spec.md` "한 장 요약"(S8) — 만드는 것 5개 / 안 만드는 것 | 빠진 게 없는지, 안 만들어도 되는지 |
| 3 디자인 | 휴대폰 크기 캡처 2장(첫 화면·핵심 화면, 라이트·다크) | 한눈에 무엇을 하는 화면인지 알겠는지 |
| 4 구현 | 로컬 또는 미리보기 주소에서 핵심 흐름 1번 직접 해 보기 | 막힌 곳·이상한 말 |
| 5 보안·법률 | 약관·처리방침 첫 문단, 운영 계정 2단계 인증 켰는지 | 연락처·운영자 이름 맞는지 |
| 6 출시 | 운영 주소를 **휴대폰·카톡**에서 열어 보기, 홍보 글 | 올려도 되는지 |
| 7 운영 | 서비스 지도(`docs/service-map.md`) — 어디에 무엇이, 장애 알림이 어디로 오는지 | 알림을 받을 곳이 맞는지 |
| 8 성장 | 지표 화면 숫자 3개 + 이번 주기 할 일 1~3개 | 우선순위 동의 |
