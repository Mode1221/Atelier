# 쉬운 말 사전 (대표에게 설명할 때)

대표는 개발을 모른다고 가정한다. 처음 쓰는 말은 아래처럼 **한 번 풀어서** 말하고, 그 뒤로는 같은 말만 쓴다.

| 말 | 쉬운 설명 |
|---|---|
| 배포 | 고친 코드를 실제 서비스 주소에 올리는 것. "배포했어요" = 사람들이 보는 화면이 바뀜 |
| 운영(프로덕션) / 스테이징 / 로컬 | 진짜 손님이 쓰는 서비스 / 올리기 전 미리보기 / 내 컴퓨터 안의 시험판 |
| 저장소(GitHub) | 코드와 변경 기록을 보관하는 곳. 서비스가 도는 곳과는 다르다 |
| 서버·Workers | 요청을 받아 화면과 데이터를 돌려주는 컴퓨터. Cloudflare Workers 는 "서버를 빌려 쓰는 것" |
| DB(데이터베이스)·D1 | 사용자가 넣은 내용이 저장되는 곳 |
| 마이그레이션 | DB 칸(표 구조)을 바꾸는 기록. 순서대로 적용해야 데이터가 안 깨진다 |
| 도메인 | 서비스 주소의 이름 부분 (`picknus.com`). 사서 1년마다 갱신 |
| DNS | 도메인 이름을 실제 서버로 연결해 주는 전화번호부 |
| API | 프로그램끼리 주고받는 창구. "API 키" = 그 창구의 열쇠 |
| 비밀값(시크릿)·토큰 | 비밀번호 같은 값. 채팅·문서·코드에 적지 않는다 |
| 환경변수 | 코드 밖에 두는 설정값 (비밀값 포함) |
| CI | 코드를 올릴 때마다 자동으로 도는 검사 |
| 테스트 (단위·E2E) | 기능이 제대로 되는지 자동으로 확인하는 것. E2E = 사람처럼 화면을 눌러 보는 테스트 |
| 롤백 | 문제가 생기면 직전 버전으로 되돌리기 |
| 헬스체크 | "서비스 살아 있어?"를 묻는 주소 (`/health`) |
| 로그 | 서비스가 한 일을 적은 기록. 문제 원인을 찾을 때 본다 |
| 지표 | 몇 명이 왔고 무엇을 했는지 숫자 |
| 캐시 | 자주 쓰는 걸 잠깐 기억해 두는 것. 바꿨는데 안 바뀌어 보이면 캐시 때문일 때가 많다 |
| 무료 등급 | 일정량까지 돈이 안 드는 사용 범위 |
| 속도 제한 | 한 사람이 너무 많이 요청하지 못하게 막는 장치 |
| 폴백 | 외부 서비스가 고장 났을 때 대신 하는 동작 |
| 소프트 삭제 | 바로 지우지 않고 "지움" 표시만 — 되살릴 수 있다 |
| OG 이미지 | 링크를 카톡·SNS 에 붙였을 때 뜨는 미리보기 그림 |
| 스토어 심사 | 앱을 올리면 애플·구글이 검토하는 과정 (며칠 걸릴 수 있음) |
| APK / TestFlight | 안드로이드 설치 파일 / 아이폰 시험 배포 앱 |
| 2단계 인증 | 비밀번호 + 휴대폰 확인. 운영 계정에는 꼭 켠다 |
