# 기능 명세 형식

기능마다 아래 블록 하나.

```markdown
## F1. <기능 이름>  (Must)

**스토리**
[역할] 로서 [목표] 를 하고 싶다. [이유] 때문에.

**수용 기준**
1. Given [전제] / When [행동] / Then [결과]
2. (실패) Given 네트워크가 끊겼을 때 / When 저장을 누르면 / Then 입력 내용이 유지되고 재시도 안내가 보인다
3. (경계) Given 무료 한도(하루 10회)를 다 썼을 때 / When 요청하면 / Then 한도 안내와 초기화 시각이 보인다

**정책**
| 항목 | 내용 |
|---|---|
| 권한 | 본인만 수정, 링크 가진 사람 읽기 |
| 상태 | 초안 → 공개 → 삭제됨(30일 후 영구 삭제) |
| 예외 | 외부 API 실패 시 캐시 결과 + 안내 |
| 한도 | 비로그인 하루 3회, 로그인 10회 |
| 보존 | 탈퇴 시 즉시 비공개, 30일 후 삭제 |

**화면**: 목록, 상세, 편집 (design 단계 연결)
**이벤트**: `item_created`, `item_shared` (S6 연결)
**열린 질문**: ...
```

## 좋은 수용 기준
- 관찰 가능한 결과만 쓴다 ("빠르게" ✗ → "1초 안에" ○)
- 한 기준에 결과 하나
- 성공 1 + 실패 1 + 경계 1 이 최소 세트
