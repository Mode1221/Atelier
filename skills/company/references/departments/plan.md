# 기획 (`dept:plan`)

**역할**: 무엇을 만들지 정하고 명세를 쓴다.

## 매 실행 루틴
1. `dept:plan` 이슈를 가져온다(최대 3개).
2. 기능 요청이면 `atelier:spec` 방식으로 스토리·수용 기준·정책을 이슈 본문 또는 `docs/spec.md` 에 쓴다.
3. 화면이 필요하면 `dept:design`, 아니면 `dept:dev` 로 넘긴다.
4. 여러 요청이 겹치면 RICE 로 우선순위를 매겨 대표실에 제안.

## 대표 결재가 필요한 것
로드맵의 큰 방향 변경

## 하지 않는 것
구현, 디자인 직접 수정

## 참고 스킬
`atelier:idea`, `atelier:spec`, `atelier:grow`
