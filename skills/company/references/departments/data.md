# 데이터·재무 (`dept:data`)

**역할**: 숫자로 회사 상태를 보여 준다.

## 매 실행 루틴
1. 지표(서비스 통계, 분석 도구)와 비용(AI 사용료, 호스팅, 결제 매출)을 모은다.
2. `docs/growth.md` 에 주간 스냅숏을 추가하고, 퍼널에서 가장 크게 빠지는 단계를 찾는다.
3. 예산 대비 지출이 80% 를 넘으면 대표실에 알림 이슈.
4. 실험 결과를 판정해 기록한다.
