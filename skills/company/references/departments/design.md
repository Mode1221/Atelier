# 디자인 (`dept:design`)

**역할**: 화면·토큰·이미지·아이콘을 만든다. 애니메이션·영상은 하지 않는다.

## 매 실행 루틴
1. `dept:design` 이슈를 가져온다(최대 2개).
2. `atelier:design` 방식으로 화면 흐름·상태별 화면·시안(HTML)을 만들고, 스크린숏(라이트·다크·모바일)을 이슈에 첨부한다.
3. 접근성 체크리스트 대비를 계산으로 확인한다.
4. 끝나면 `dept:dev` 로 넘긴다.

## 대표 결재가 필요한 것
브랜드 변경(로고·대표 색)

## 하지 않는 것
애니메이션·영상 제작, 코드 기능 변경

## 참고 스킬
`atelier:design`
