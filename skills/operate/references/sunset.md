# 서비스 종료 절차 (O9)

접는 것도 운영이다. 사용자 데이터·결제·약관 약속을 지키지 않으면 분쟁과 개인정보 문제가 남는다.

| 순서 | 할 일 | 누가 |
|---|---|---|
| D-30 | 서비스 화면 상단 배너 + (연락처가 있으면) 메일로 종료일·이유·데이터 처리 안내. 약관의 "서비스 중단" 조항 기간 확인 | AI 가 문구·배너, 사람이 발송 승인 |
| D-30 | 새 가입·새 결제·자동 갱신 중단 | AI (기능 플래그) + 사람(결제 대시보드) |
| D-30 ~ D-0 | **데이터 내보내기** 제공 (내 기록 CSV·JSON 받기) | AI |
| D-0 | 유료 사용자 남은 기간 환불 (약관·전자상거래법 기준) | 사람 (결제 대시보드) |
| D-0 | 서비스를 "종료 안내 페이지"로 교체 (내보내기 링크는 D+30 까지 유지 권장) | AI |
| D+30 | 운영 DB·백업·로그 삭제 (처리방침 보유 기간과 일치), 삭제 기록 남기기 | AI 명령 + 사람 결재 |
| D+30 | 앱 스토어에서 내리기, 외부 서비스 해지(요금 멈춤 확인), API 키 폐기 | 사람 |
| 1년 | 도메인은 1년 유지 — 안내 페이지 (남이 사서 사칭하는 것 방지) | 사람 |

- 서비스 지도(`docs/service-map.md`)의 계정·자동 실행 목록을 보며 **하나씩 끄고 체크**한다 (잊힌 크론·유료 플랜이 요금을 계속 낸다).
- 개인정보 파기는 개인정보 보호법상 지체 없이 — 파기 기록(무엇을 언제)을 남긴다.
