# 릴리스 관리

## 버전
- 유의적 버전(SemVer) `주.부.수`: 호환 깨짐.기능 추가.버그 수정
- 앱: 사용자에게 보이는 버전 + 매 빌드 증가하는 빌드 번호
- 커밋 메시지(Conventional Commits)로 변경 기록 자동 생성 가능

## CHANGELOG.md
```markdown
## [1.2.0] - 2026-10-01
### 추가
### 변경
### 수정
```
사용자용 업데이트 노트는 따로: 기술 용어 없이 "무엇이 좋아졌나"

## 배포 방식
| 형태 | 방법 |
|---|---|
| 웹 | 기능 플래그로 일부 사용자에게 먼저 → 전체 |
| iOS | 단계적 출시(phased release) |
| Android | 단계적 출시(비율 지정), 문제 시 중지 |
| 게임 (Steam) | 베타 브랜치 → 기본 브랜치 |

## 앱 강제 업데이트
- 서버에 "최소 지원 버전" 설정 → 앱 시작 시 비교 → 미만이면 업데이트 화면
- API 는 구버전 앱을 한동안 지원 (호환 기간 정하기)
- 첫 출시 버전부터 이 기능이 있어야 한다 (나중에 넣으면 이미 깔린 앱은 못 막는다)
