# 고객 지원·피드백

## 창구
- 하나로 모은다: 앱 내 문의(권장) 또는 이메일 한 곳. 기기·버전·사용자 ID 를 자동 첨부
- **국내 대상이면 카카오톡 채널을 선택지로 제시한다** — 국내 사용자가 가장 먼저 찾는 창구다.
| | 카카오톡 채널 | 이메일 |
|---|---|---|
| 사용자 | 앱 설치 필요 없음(카톡), 답장이 빠르다고 기대 | 누구나, 느린 답장도 받아들임 |
| 운영 | 휴대폰으로 바로 답장, 자동 응답(운영 시간·FAQ 링크), 1:1 채팅 | 템플릿·검색·기록이 쉬움 |
| 준비 | 카카오톡 채널 관리자센터에서 개설(사람, 10분), 채널 URL 을 서비스·처리방침에 | 서비스 도메인 주소 권장(support@…) |
| 주의 | 채널 친구에게 보내는 메시지는 광고성 정보 규칙(수신 동의·"(광고)" 표시) | 스팸함 |
  공식: [카카오톡 채널 관리자센터](https://center-pf.kakao.com) (2026-10-01 기준 주소, 개설 절차는 공식 도움말에서 확인).
  고른 창구는 처리방침의 "개인정보 보호책임자 연락처"·이용약관 문의처와 같게 맞춘다(guard G4).
- 커뮤니티(Discord·오픈 카톡)는 공지·토론용. 개인정보가 오가는 문의는 1:1 로
- 스토어 리뷰에도 답변 (특히 낮은 평점)

## 응답 기준 (1인 현실 기준 예)
| 유형 | 첫 응답 목표 |
|---|---|
| 결제·환불·계정 접근 불가 | 24시간 |
| 버그 | 48시간 |
| 기능 요청·기타 | 1주 |
자동 응답에 이 기준과 FAQ 링크를 넣는다.

## FAQ (출시 전 준비)
가격·환불, 탈퇴·데이터 삭제, 지원 기기, 개인정보, 알려진 문제

## 답변 템플릿
- 버그 접수: 감사 → 재현 정보 요청(기기·시각·화면) → 처리 예정 안내
- 기능 요청: 감사 → 기록했다고 안내 → (약속하지 않음)
- 환불: 정책 인용 → 처리 방법·기간

## 신고·운영 정책 (사용자 콘텐츠가 있으면)
- 신고 → 확인 → 숨김/유지/계정 조치 → 신고자에게 결과
- 불법 촬영물·아동 대상 등 법적 대응 필요 콘텐츠의 처리 절차 확인
- 처리 기록 보관

## 피드백 → 제품
- 모든 문의에 태그: 버그 / 사용성 / 기능 요청 / 결제 / 칭찬 / 이탈 이유
- 매주 태그별 건수·대표 문장 → grow R6 로 넘김
- 요청을 반영하면 요청한 사람에게 알린다
