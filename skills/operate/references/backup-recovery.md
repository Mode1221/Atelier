# 백업·복구

## 백업 대상
| 대상 | 방법 | 주기 | 보관 |
|---|---|---|---|
| DB | 관리형 DB 자동 백업 / `pg_dump` 크론 | 일 1회 이상 | 7~30일 |
| 업로드 파일 | 스토리지 버전 관리·복제 | 연속 | 정책대로 |
| 설정·환경변수 | 비밀번호 관리자 (값), 저장소 (이름) | 변경 시 | — |
| 앱 서명 키·인증서 | 오프라인 + 비밀번호 관리자 | 생성 시 | 영구 |
| 도메인·계정 복구 코드 | 비밀번호 관리자 | 생성 시 | 영구 |

## 원칙
- 백업은 **다른 계정·다른 위치**에도 한 벌 (호스팅 계정 정지·삭제 대비)
- 백업 암호화, 접근 권한 최소화
- 개인정보 보유 기간이 지난 데이터는 백업에서도 파기 주기에 맞춘다

## 복구 실습 (분기 1회)
1. 최신 백업을 **별도 환경**에 복구
2. 앱을 연결해 핵심 흐름 동작 확인
3. 걸린 시간 기록 → spec S5 복구 목표와 비교
4. 절차를 `docs/runbook.md` 에 명령어로 갱신
