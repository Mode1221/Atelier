# Design — 디자인

## 절차
1. MVP 기능 기준으로 화면 흐름을 만든다 (화면 목록 + 이동 관계).
2. 디자인 토큰(색·타이포·간격·반경)을 정의한다. 라이트·다크 모두.
3. 핵심 화면 2~3개 시안을 HTML 로 만들어 보여준다.
4. 확정 결과를 `docs/design.md` 와 토큰 파일로 저장한다.

## 기준
- 모바일 우선, 접근성(명도 대비 4.5:1, 터치 영역 44px)
