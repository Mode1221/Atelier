# 브랜드 에셋 규격

규격은 플랫폼 정책에 따라 바뀐다. 제출 전 공식 가이드에서 최신 규격을 확인한다.

## 공통
- 로고: 가로형·정사각형, SVG 원본 보관
- 컬러 팔레트·폰트는 디자인 토큰과 일치

## 웹
| 에셋 | 규격 |
|---|---|
| 파비콘 | SVG + 32×32 PNG, `apple-touch-icon` 180×180 |
| OG 이미지 | 1200×630 (링크 공유 미리보기) |
| PWA 아이콘 | 192×192, 512×512 (+ maskable) |

## iOS
- 앱 아이콘 1024×1024 PNG (투명 배경 없음, 모서리 둥글림은 시스템이 처리)
- 스크린샷: 스토어 요구 기기 크기별

## Android
- 적응형 아이콘: 전경·배경 레이어 (108dp 기준, 중앙 안전 영역)
- Play 스토어 아이콘 512×512, 그래픽 이미지 1024×500
- 스크린샷: 휴대폰 최소 2장

## 게임 (Steam 등)
- 캡슐 이미지 여러 규격, 라이브러리 이미지, 트레일러
- itch.io 커버 이미지

## 점검
- [ ] 작은 크기(16~32px)에서도 알아볼 수 있는가
- [ ] 다크 배경·라이트 배경 모두에서 보이는가
- [ ] 타사 상표와 헷갈리지 않는가
