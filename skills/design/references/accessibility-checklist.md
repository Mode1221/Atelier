# 접근성 체크리스트

기준: WCAG 2.2 AA (웹), Apple HIG, Material Design. 앱·웹 공통으로 확인한다.

## 인지 (보이는가)
- [ ] 본문 텍스트 대비 **4.5:1 이상**, 큰 텍스트(24px 이상, 또는 굵게 18.66px 이상) **3:1 이상** — WCAG 1.4.3
- [ ] 아이콘·입력 테두리·포커스 표시 등 비텍스트 요소 대비 **3:1 이상** — WCAG 1.4.11
- [ ] 색만으로 정보를 전달하지 않는다(오류는 색 + 아이콘/문구)
- [ ] 글자 크기 200% 확대(또는 OS 큰 글씨)에서도 깨지지 않는다
- [ ] 의미 있는 이미지에 대체 텍스트, 장식 이미지는 숨김 처리
- [ ] 영상 자막(있다면)

## 조작 (누를 수 있는가)
- [ ] 터치 영역: Apple **44×44pt**, Android **48×48dp** 권장. WCAG 최소 24×24 CSS px — 2.5.8
- [ ] 키보드만으로 모든 기능 사용 가능(웹), 포커스 순서가 논리적
- [ ] 포커스 표시가 보인다 — WCAG 2.4.7
- [ ] 드래그만 가능한 동작에 대안(버튼) 제공 — WCAG 2.5.7
- [ ] 시간 제한이 있으면 연장·해제 가능
- [ ] 깜빡임 초당 3회 이하 — WCAG 2.3.1 (게임 특히 주의)

## 이해 (알 수 있는가)
- [ ] 입력 필드에 보이는 레이블(placeholder 만으로 대체 금지)
- [ ] 오류 메시지가 원인과 해결법을 말한다
- [ ] 같은 기능은 같은 이름·위치
- [ ] 페이지·화면 언어 지정(`<html lang="ko">`)

## 호환 (보조기기가 읽는가)
- [ ] 버튼은 `<button>`, 링크는 `<a>` — 시맨틱 요소 우선
- [ ] 아이콘 전용 버튼에 접근성 이름(`aria-label` / `accessibilityLabel`)
- [ ] 스크린리더(VoiceOver / TalkBack)로 핵심 흐름 1회 통과

## 모션
- [ ] `prefers-reduced-motion` 존중
- [ ] 자동 재생 애니메이션 5초 넘으면 정지 가능

## 게임 추가 항목
- [ ] 자막·자막 크기 조절
- [ ] 키 재배치
- [ ] 색각 이상 모드 또는 색 외 구분 요소
- [ ] 난이도·보조 옵션

## 확인 방법
- 대비: 토큰 값으로 WCAG 상대 휘도 공식을 계산한다(스크립트 가능).
- 자동 점검: 웹은 axe-core / Lighthouse 접근성 점수.
- 자동 점검은 일부만 잡는다. 스크린리더 수동 확인을 반드시 1회 한다.
