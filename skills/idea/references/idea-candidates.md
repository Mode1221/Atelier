# 아이디어 후보 거름망 (I0)

후보를 사용자에게 보여 주기 **전에** AI 가 스스로 거른다. 예시 `examples/chaenggim-pyo` 에서 대표가 후보를 세 번 되돌려 보낸 이유(필요성·선점·무게)를 기본 거름망으로 만들었다.

| # | 거름망 | 통과 기준 | 확인 방법 |
|---|---|---|---|
| 1 | 실제 불편 | 대상이 한 달에 한 번 이상, 또는 행사마다 반드시 겪는다 | 커뮤니티·Q&A 에 같은 불평 글 (링크) |
| 2 | 돈·시간 신호 | 지금 돈(유료 앱·대행)이나 시간(엑셀·단톡 30분)을 쓰고 있다 | 유료 대안 존재, 불평 글의 "매번 ○분" |
| 3 | 선점 안 됨 | 같은 대상·같은 차별점의 전용 서비스가 없다 | 웹 검색 2~3번 (서비스명·기능·"앱" 키워드), 앱스토어. 찾은 곳은 링크 |
| 4 | 가벼움 | 시작할 때 부담 없는 주제 (사용자가 무거운 주제를 원하면 예외) | 가족 갈등·이혼·질병·법적 분쟁·빚은 "무거움" |
| 5 | 1인 크기 | 무료 스택으로 4~8주, Must 5개 이하 | `../../build/references/free-tier.md` |
| + | 퍼짐 구조 (가산점) | 쓰는 사람이 다른 사람을 데려온다 (링크 공유·초대) | 흐름에 "링크 보내기"가 들어가나 |

## 보여 주는 형식 (후보마다 한두 줄)
> **캠핑·여행 준비물 분담** — 3~10명 여행 총무, 단톡방에서 "누가 뭘 가져와?" 반복. 선점: 캠핑 앱은 예약 위주, 분담 전용 없음 ([출처](https://…)). 돈: 직접 과금 약함 → 장비 대여·구매 제휴.

## 거절당했을 때
- 거절 이유를 한 줄 거름망으로 바꿔 표에 추가한다 (예: "너무 무겁다" → 4번 강화, "이미 있을 것 같다" → 3번 검색 횟수 늘리기).
- 새 후보 3개는 **새 거름망까지** 통과한 것만.
- 결정 기록: `| 날짜 | 후보 거절 (이유) → 거름망 추가 | … |`
