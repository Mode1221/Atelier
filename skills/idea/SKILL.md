# Idea — 아이디어 검증

## 절차
1. 문제·대상 사용자를 한 문장으로 정리한다.
2. 경쟁 서비스 3~5개를 웹 검색으로 조사한다: 기능, 가격, 평점, 불만 리뷰.
3. 차별점을 정리한다.
4. MVP 기능을 Must / Should / Won't 로 나눈다. Must 는 5개 이하.
5. 결과를 `docs/idea.md` 에 저장하고 PROJECT.md 체크박스를 갱신한다.

## 완료 조건
- MVP Must 목록 확정, 경쟁 분석 문서 존재
