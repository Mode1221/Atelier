# 자체 도메인 연결·주소 이전 (B15)

무료 주소(`*.workers.dev`, `*.pages.dev`, duckdns 등)로 시작해도 된다. 도메인은 **대표가 결정하고 산다**(연 1~3만 원, 카드).

## 1. 고르기·사기 (사람)
- `.com` 이 비었으면 우선, 한국 대상이면 `.kr`·`.co.kr` 도. 이름은 idea I7 의 상표 확인을 통과한 것.
- 살 곳: Cloudflare Registrar(원가, DNS 가 바로 연결됨) 권장. 다른 곳에서 샀으면 네임서버를 Cloudflare 로 바꾼다.
- 자동 갱신 켜기, 갱신일을 `docs/ops/expiry.txt` 와 서비스 지도에.

## 2. 서비스에 붙이기 (AI, Cloudflare Workers 기준)
- `wrangler.toml` 에 `routes = [{ pattern = "example.com", custom_domain = true }]` (www 도 쓰면 추가) → 배포. 인증서는 자동.
- 다른 호스팅이면 해당 플랫폼의 "custom domain" 절차 (DNS 레코드 값은 AI 가 알려 주고 사람은 붙여 넣기만).

## 3. 옛 주소 넘겨주기 (이미 알린 주소가 있으면 필수)
- 옛 주소로 오는 요청을 **경로 그대로** 새 주소로 301 이동 (`/t/abc` → `https://new/t/abc`). 공유된 링크가 죽지 않게.
- 비밀 링크가 조각(`#k=…`)에 있으면 브라우저가 이동 뒤에도 유지한다 — 한 번 실제로 확인.
- 옛 주소는 최소 1년 유지.

## 4. 주소가 들어간 곳 모두 바꾸기 (빠뜨리기 쉬움)
| 곳 | 예 |
|---|---|
| 코드·설정 | 기본 주소 상수, CORS 허용 목록, 로그인 콜백·리다이렉트 URL(카카오·구글·Supabase 콘솔) |
| 화면 | OG 이미지·공유 문구의 주소, 사이트맵, robots |
| 문서 | 약관·처리방침의 주소, README, 서비스 지도, 홍보 글(`docs/share/posts.json`) |
| 운영 | 헬스체크·지킴이·정기 점검 주소, 의견 수집 워크플로의 SERVICE_URL |
| 외부 | Search Console·서치어드바이저에 새 속성 + 주소 변경 알림, 앱 스토어 지원 URL |

## 5. 확인
- 새 주소 `/health` 200, 옛 주소 301 → 새 주소, 로그인·결제 콜백 1회씩, 공유 미리보기(OG) 1회.
- 운영 E2E·스모크의 기본 주소도 새 주소로.
