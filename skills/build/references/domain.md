# 자체 도메인 연결·주소 이전 (B15)

무료 주소(`*.workers.dev`, `*.pages.dev`, duckdns 등)로 시작해도 된다. 도메인은 **대표가 결정하고 산다**(연 1~3만 원, 카드).

## 1. 고르기·사기 (사람)
- `.com` 이 비었으면 우선, 한국 대상이면 `.kr`·`.co.kr` 도. 이름은 idea I7 의 상표 확인을 통과한 것.
- 살 곳: Cloudflare Registrar(원가, DNS 가 바로 연결됨) 권장. 다른 곳에서 샀으면 네임서버를 Cloudflare 로 바꾼다.
  - `.kr` 처럼 Cloudflare 에서 못 사는 확장자는 국내 등록 대행(가비아·후이즈 등)에서 사고 네임서버만 Cloudflare 로.
  - 가격은 **첫해 할인가가 아니라 갱신가**로 비교한다(공식 가격표에서 확인, 확인일을 적는다). 개인정보 보호(WHOIS 비공개)가 무료인지도 본다.
- 자동 갱신 켜기, 갱신일을 `docs/ops/expiry.txt` 와 서비스 지도에.

## 2. 서비스에 붙이기 (AI, Cloudflare Workers 기준)
- `wrangler.toml` 에 `routes = [{ pattern = "example.com", custom_domain = true }]` (www 도 쓰면 추가) → 배포. 인증서는 자동.
- 다른 호스팅이면 해당 플랫폼의 "custom domain" 절차 (DNS 레코드 값은 AI 가 알려 주고 사람은 붙여 넣기만).

## 이전 순서 (이미 쓰던 주소가 있으면 이 순서를 지킨다)
1. 새 주소 DNS 연결 → 2. 새 주소로도 배포(두 주소 모두 응답) → 3. 외부 콘솔에 새 주소를 **추가**(옛 것은 지우지 않음: 4절 "외부" 줄) → 4. 새 주소로 로그인·결제·지도·공유 미리보기 확인 → 5. 옛 주소 301 켜기 → 6. 공유된 링크·홍보 글 교체 → 7. 몇 주 뒤 외부 콘솔의 옛 주소 정리(옛 주소 자체는 1년 유지).
순서가 뒤집히면(301 을 먼저 켜고 콘솔을 나중에) 그 사이 로그인·결제가 끊긴다.

## 3. 옛 주소 넘겨주기 (이미 알린 주소가 있으면 필수)
- 옛 주소로 오는 요청을 **경로 그대로** 새 주소로 301 이동 (`/t/abc` → `https://new/t/abc`). 공유된 링크가 죽지 않게.
- 비밀 링크가 조각(`#k=…`)에 있으면 브라우저가 이동 뒤에도 유지한다 — 한 번 실제로 확인.
- 옛 주소는 최소 1년 유지.

## 4. 주소가 들어간 곳 모두 바꾸기 (빠뜨리기 쉬움)
| 곳 | 예 |
|---|---|
| 코드·설정 | 기본 주소 상수, CORS 허용 목록, 로그인 콜백·리다이렉트 URL(카카오·구글·Supabase 콘솔) |
| 화면 | OG 이미지·공유 문구의 주소, 사이트맵, robots |
| 문서 | 약관·처리방침의 주소, README, 서비스 지도, 홍보 글(`docs/share/posts.json`) |
| 운영 | 헬스체크·지킴이·정기 점검 주소, 의견 수집 워크플로의 SERVICE_URL |
| 로그인 콘솔 | 카카오(사이트 도메인·리다이렉트 URI), 네이버(서비스 URL·Callback URL), 구글(승인된 리디렉션 URI·도메인) — **추가 후** 확인, 정리는 나중. 콘솔에 따라 재검수가 필요할 수 있다(`../../guard/references/platform-review-kr.md`) |
| 지도·장소 API | 카카오맵·네이버 지도·구글 Maps 키의 **허용 도메인(리퍼러)** 에 새 주소 추가 — 빠뜨리면 지도가 빈 화면 |
| 결제 | PG 가맹점 관리자에 등록한 사이트 주소·결제 완료/웹훅 주소, 스토어 결제의 서버 알림 주소 |
| 외부 | Search Console·서치어드바이저에 새 속성 + 주소 변경 알림, 앱 스토어 지원 URL, SNS 프로필 링크, 문의 채널(카카오톡 채널) 링크 |

## 5. 확인
- 새 주소 `/health` 200, 옛 주소 301 → 새 주소, 로그인(서비스별)·결제 콜백 1회씩, 지도 1회, 공유 미리보기(OG) 1회.
- 위 표 줄마다 ✅ 를 `docs/build.md` "주소 이전" 표에 남긴다 — 빠진 줄이 0개여야 끝.
- 운영 E2E·스모크의 기본 주소도 새 주소로.
