# 성능·SEO·다국어

## 성능 (spec S5 목표로 측정)
- 웹: Core Web Vitals — LCP 2.5초 이하, INP 200ms 이하, CLS 0.1 이하 (Lighthouse·PageSpeed Insights)
- 이미지: 적정 크기·현대 포맷(WebP/AVIF)·지연 로딩
- 번들: 필요한 것만, 코드 분할
- API: 느린 쿼리 찾기(인덱스), N+1 제거, 캐시
- 앱: 콜드 스타트 시간, 메모리, 배터리. 목록은 가상화
- 게임: 목표 프레임 유지, 저사양 기기 확인, 로딩 시간

## SEO (웹, 검색 유입이 필요할 때)
- [ ] 페이지별 `<title>`, meta description, OG 태그
- [ ] 서버 렌더링 또는 정적 생성 (검색에 필요한 페이지)
- [ ] `sitemap.xml`, `robots.txt`, canonical
- [ ] 의미 있는 URL, 제목 구조(h1~h3)
- [ ] Google Search Console·네이버 서치어드바이저 등록 (사람)
- [ ] 로그인 뒤 페이지·스테이징은 색인 제외

## 다국어 (해외 대상일 때)
- [ ] 문자열을 코드에서 분리 (i18n 라이브러리)
- [ ] 날짜·숫자·통화 형식 지역화
- [ ] 텍스트 길이 변화에 레이아웃이 버티는가
- [ ] 처리방침·약관·스토어 문구 번역
- 처음부터 할 필요는 없지만, **문자열 분리**는 처음부터 해 두면 나중이 쉽다.
