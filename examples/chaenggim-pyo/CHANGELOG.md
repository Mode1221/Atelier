# Changelog

## [0.2.0] - 2026-09-30
### 추가
- 되돌리기: 지운 준비물·낸 돈을 "최근 변경"에서 7일 동안 되살리기, 누가 무엇을 했는지 기록
- 고치기: 준비물 이름·수량, 목록 이름·날짜
- 자동 새로고침(15초, 입력 중이면 알림 막대), 지표 화면 `/stats`
- 운영: 매시간 운영 점검(이슈 알림), 서비스 지킴이 자동 설치(알림 주제가 있을 때)

## [0.1.0] - 2026-09-30 (공개 베타)
### 추가
- 목록 만들기(캠핑·여행·MT·바비큐·빈 목록 템플릿), 가입 없는 참여("나는 누구"), 공용 준비물 맡기·챙김·취소·추가·삭제, 각자 챙길 것
- 장본 돈 나누기: 사람별 낸 돈·부담·차액, 최소 송금 안내
- 카톡용 현황 복사·공유, 초대 링크, 관리 링크(사람 내보내기·목록 삭제)
- 의견 보내기(연락처 자동 가림)·수집 API, 운영 지표 API, 후원 링크(선택)
### 변경
- AI 대리 사용성 테스트 반영: 참여 직후 바로 맡을 수 있게, "장본 돈 나누기 · n빵 정산", 초대 카드 위로
