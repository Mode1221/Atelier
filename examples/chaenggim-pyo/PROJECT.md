# 챙김표

## 개요
- 한 줄 설명: 캠핑·여행·MT 준비물을 누가 뭘 챙길지 링크 하나로 나누고, 장본 돈까지 n빵하는 가입 없는 웹
- 대상 사용자 / 해결하는 문제: 3~10명 여행·캠핑 모임 총무와 친구들 / 단톡방에서 준비물이 겹치거나 빠지고, 장본 돈은 따로 계산 (가정)
- 목표 일정 / 주당 시간: 1주 / 주 20시간 (가정)

## 프로필
- 형태: 웹 (모바일 우선)
- 과금: 없음 (MVP). 수익: 후원 → 캠핑 장비 대여·구매 제휴 → 프로 (docs/monetization.md)
- 계정: 없음 (링크 권한 + 관리 링크)
- 사용자 데이터 저장: 있음 (목록·참여자 이름·준비물·지출)
- 경험 수준: 비전공자 (가정) — 관리형 무료 스택
- 스택: Cloudflare Workers + D1 + Hono, 서버 렌더링 HTML (벌금장부와 같은 무료 스택)
- 예산: 무료 우선 — 운영비 0원 (docs/costs.md)

## 현재 단계
