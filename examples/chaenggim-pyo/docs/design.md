# 디자인 — 챙김표

> Atelier `design` 스킬. 도구 선택은 PROJECT.md "디자인 도구 계획"(절약 모드, 외부 디자인 스킬 미설치 → 대체 수단).

## D0. 방향 (design-direction.md)
- 주제에서 나온 방향: **캠핑 체크리스트 종이** — 크라프트 종이 배경(#fbf8f1), 숲 초록(#1f5d3f) 주 색, 모닥불 주황(#a4410f)은 **"아직 없음" 한 곳에만** 대담하게.
- 피한 AI 티: 보라 그라데이션, 유리 효과, 이모지 장식, 카드 속 카드. 제목은 짧은 두 줄 약속("누가 뭘 챙길지, 링크 하나로.").

## D1. 여정
총무: 첫 화면 → 목록 만들기(템플릿) → 관리 링크 저장 안내 → 내 이름 → 초대 링크 복사 → 단톡방.
친구: 초대 링크 → 이름 적기 → "주인 없음" 필터 → "내가 챙길게" → 장본 돈 → 송금 안내 확인.

## D2. 화면 구조 (목록 화면, 위에서 아래)
제목·날짜·참여 수 → (관리 링크 안내) → **나는 누구예요?** → **친구 초대**(링크·카톡용 현황 복사) → 함께 쓸 준비물(진행 막대, 필터, 목록, 추가) → 각자 챙길 것 → 장본 돈 나누기(송금 안내·표·기록 폼) → (관리) → 새 목록 안내.
상태: 빈 목록 / 이름 안 고름("먼저 내 이름을 골라 주세요") / 이미 맡음(409 안내) / 네트워크 실패 / 필터 결과 없음 / 모두 정산됨 / 없는 목록 404.

## D3. 토큰
`public/static/tokens.css` (라이트·다크), 컴포넌트 `app.css` 는 토큰만 사용. 터치 44px.

## D4. 시안 — 실제 화면 캡처 (Playwright 스크립트)
`design/shots/` (home·trip × light·dark). 자체 검토(design-direction.md 5절) 1회:
| 발견 | 조치 |
|---|---|
| 초대 링크가 맨 아래에 묻힘 — 총무의 다음 할 일이 안 보임 | "친구 초대" 카드를 "나는 누구" 바로 아래로 |
| 초록 채움 버튼 16개가 벽처럼 보임, "아직 없음" 신호가 묻힘 | "내가 챙길게"를 외곽선 버튼으로, 주황 "아직 없음"이 눈에 띄게 |

## D5. 프로토타입 테스트
AI 대리 사용성 테스트로 대체 (`docs/usertest/2026-09-30.md`).

## D6. 접근성
axe 자동 검사 라이트·다크 위반 0 (E2E), 모든 입력 라벨, 버튼 이름에 준비물 이름 포함("텐트 내가 챙길게"), 챙김 버튼 `aria-pressed`, 토스트 `aria-live`, 포커스 링 3px.

## D7. 브랜드 에셋
아이콘(텐트 + 체크) `public/static/favicon.svg`, `apple-touch-icon.png`(180), OG `og.png`(1200×630) — 원본 `design/assets/*.html` 을 Playwright 로 캡처.
