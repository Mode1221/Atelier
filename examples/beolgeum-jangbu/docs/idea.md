# 아이디어 검증 — 벌금장부

> Atelier `idea` 스킬로 작성. 사용자 인터뷰·실제 검증은 하지 않은 **가정 기반** 문서다.

## I1. 문제 정의
> **소규모 스터디·운동 모임(3~15명) 운영자**는 **매주 모임 뒤 지각·결석·과제 미제출 벌금을 계산할 때**
> **누가 얼마를 냈고 안 냈는지 헷갈리는 문제**를 겪는다. 지금은 **단톡방 메시지 + 엑셀/메모장**으로 버티지만
> **기록이 흩어지고, 정산 때마다 다시 계산하고, "내가 왜 이만큼 내?" 분쟁이 생긴다.**

첫 사용자 100명이 모인 곳: 대학 커뮤니티 스터디 게시판, 오픈 카톡 스터디방, 러닝 크루, 자격증 스터디 카페.

## I2. 경쟁·대안
| 서비스 | 핵심 기능 | 가격 | 형태 | 약점·불만 (추정 포함) | 우리가 다른 점 |
|---|---|---|---|---|---|
| 뜨끔 (스터디 그룹 관리 앱) | 스터디 그룹 관리 | 무료(추정) | 앱 설치·가입 | 전원 설치·가입 필요 → 소규모 모임엔 진입 장벽 | 링크 하나, 가입 없음 |
| 엑셀·구글 시트 | 자유 형식 | 무료 | 웹 | 수식·공유 설정 번거로움, 모바일 입력 불편 | 규칙만 정하면 자동 계산, 모바일 우선 |
| 단톡방 공지 + 메모장 | 기록 | 무료 | — | 기록 흩어짐, 검색 어려움 | 한 페이지에 누적 기록 |
| 카카오뱅크 모임통장 등 | 회비 입출금 | 무료 | 앱 | 돈 보관은 되지만 "누가 왜 얼마" 규칙 계산은 없음 | 규칙 → 금액 계산에 집중 (돈은 안 만짐) |

## I4. 수요 검증 (계획 — 사람이 할 일)
| 방법 | 내용 | 성공 기준 |
|---|---|---|
| 커뮤니티 불만 조사 | "스터디 벌금 정산" 관련 글 20개 읽기 | 같은 불편 반복 5건 이상 |
| 문제 인터뷰 5명 | 스터디 운영자 대상 Mom Test 질문 | 3명 이상이 지금 엑셀·메모로 관리 중 |
| 대기자 명단 없이 **바로 MVP** | 만드는 비용이 낮아(2~3주) 랜딩 대신 MVP 로 검증 | 출시 4주 내 활성 모임 30개 |

## I5. 사업성
| 항목 | 월 고정비 | 사용자당 변동비 | 비고 |
|---|---|---|---|
| 호스팅·DB | 0원 (무료 한도) → 초과 시 약 1만 원 | ≈0 | 텍스트 데이터만, 모임당 수 KB |
| 외부 API | 0 | 0 | 없음 |
| 도메인 | 약 2천 원 (연 2만 원 ÷ 12) | — | |
| 결제 수수료 | — | — | MVP 과금 없음 |

- 손익분기: 과금 전까지 월 비용 약 1.2만 원. 유료 전환 시 월 2,900원 × (1 − 수수료 약 10%) ≈ 2,600원 → **유료 모임 5개**면 비용 충당.
- 필요 전체 모임 수: 유료 전환율 3% 가정 → 약 170개 활성 모임.
- 공헌이익률: 변동비가 거의 0 → 높음.
- **가장 불확실한 가정**: ① 운영자가 매주 체크하는 습관이 생기는가 ② 소규모 모임이 월 2,900원을 낼 동기가 있는가.

## I6. MVP 범위
| 기능 | 분류 | 이유 |
|---|---|---|
| 모임 만들기 (이름·벌금 규칙: 지각/결석/과제 금액) | Must | 핵심 |
| 멤버 추가·삭제 | Must | 핵심 |
| 회차별 출결 체크 (출석/지각/결석/과제 미제출) → 벌금 자동 계산 | Must | 핵심 가치 |
| 멤버별 누적·납부·미납 요약 + 납부 처리 | Must | 정산 분쟁 해결 |
| 공유 링크 (보기 전용) + 관리 링크 (편집) | Must | 가입 없음 = 차별점 |
| 정산 요약 복사(카톡 붙여넣기용 텍스트) | Should | 바이럴·편의 |
| 규칙 변경 이력 | Should | 분쟁 방지 |
| 멤버 본인 체크인 | Could | 운영자 부담 감소 |
| 계좌 송금 연동·결제 | Won't | 돈을 만지면 규제·책임 증가 |
| 회원가입·로그인 | Won't | 차별점과 충돌 |
| 앱 | Won't | 웹(모바일)으로 충분 |

Must 5개. 1인 기준 2~3주 규모.

### 중단 기준
- 출시 4주 후 **주간 출결 기록이 있는 모임 10개 미만**이면 문제 정의를 다시 본다 (인터뷰 결과와 함께).
- 만든 모임 중 **2주 차에도 기록하는 비율 20% 미만**이면 습관 형성 실패 → 멤버 본인 체크인·알림을 검토하거나 중단.
