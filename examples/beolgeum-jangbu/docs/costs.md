# 비용 — 벌금장부

> Atelier 무료 우선 원칙. 무료 한도는 바뀔 수 있으니 분기마다 Cloudflare 요금 페이지에서 확인한다.

## 지금 드는 비용: 0원
| 항목 | 쓰는 것 | 무료 한도 (2026-09 기준, 확인 필요) | 우리 사용량 추정 |
|---|---|---|---|
| 서버 | Cloudflare Workers | 하루 요청 10만 건 | 활성 모임 100개 × 하루 50요청 = 5천 |
| DB | D1 | 저장 5GB, 하루 읽기 500만 행 / 쓰기 10만 행 | 모임당 수 KB, 쓰기 하루 수천 |
| 정적 파일 | Workers 정적 자산 | 무제한 요청 (정적 자산은 요청 한도에 안 셈) | — |
| 예약 작업 | Cron Triggers | 무료 | 하루 1회 |
| 백업 | D1 Time Travel | 무료 등급 7일 복구 | 자동 |
| 도메인 | `*.workers.dev` | 무료 | 사용 |
| CI/CD | GitHub Actions | 공개 저장소 무료 / 비공개 월 2,000분 | 배포당 약 3분 |

## 돈이 드는 순간 (미리 안내)
| 언제 | 무엇 | 대략 비용 | 대안 |
|---|---|---|---|
| 하루 요청 10만 건을 넘기면 | Workers 유료 플랜 | 월 $5 부터 | 넘기기 전 캐시 강화 |
| 자기 도메인을 쓰고 싶으면 | 도메인 등록 | 연 1~2만 원 | workers.dev 주소 유지 |
| 30일 넘는 백업이 필요하면 | 객체 저장소(R2 무료 10GB) 또는 유료 | 대부분 0원 | 주 1회 export 를 R2 에 |
| 오류 알림 서비스를 붙이면 | Sentry 등 | 무료 등급 있음 | Workers 로그 + 정기 점검 |
