# 수익화 — 벌금장부 (R4)

> 원칙: 사용자가 생기기 전 과금은 성장만 막는다. **지표가 문턱을 넘을 때만** 다음 단계로 간다. 운영비는 0원이므로 서두를 이유가 없다.

## 단계
| 단계 | 방식 | 켜는 조건 | 필요한 것 | 비용 |
|---|---|---|---|---|
| **1 후원** (지금) | 푸터 "☕ 개발자 응원하기" → 송금 링크 | 바로 | 토스 익명 송금 링크(toss.me) 또는 카카오페이 송금 코드 | 0원, 수수료 0 |
| 2 광고 | 보기 페이지 하단 배너 1개 (관리 화면엔 없음) | 주간 기록 모임 50개 ↑ | Kakao AdFit 가입·심사, 개인정보처리방침에 광고 쿠키 추가, CSP 수정 | 0원 (수익 배분) |
| 3 프로 | 월 2,900원: 모임 여러 개 묶기·엑셀 내보내기·지난 기록 무제한 | 주간 기록 모임 170개 ↑ 그리고 인터뷰에서 3명 이상 "돈 내겠다" | 사업자등록·통신판매업 신고, 결제(토스페이먼츠) 계약, 약관·환불 규정 | 결제 수수료 약 3.3% |

- 후원은 금액이 작고 대가가 없어 사업자등록이 필요 없다. 다만 연간 받은 금액은 종합소득세 신고 대상이 될 수 있다 — 금액이 커지면 세무 상담.
- 광고는 멤버 이름이 보이는 페이지에 붙이므로, 광고 쪽으로 이름·금액이 넘어가지 않게(리퍼러 없음 유지) 확인 후 켠다.

## 지금 켜는 방법 (1 후원)
1. 토스 앱 → 전체 → "토스아이디" 만들기 → 링크 `https://toss.me/<아이디>` 복사.
2. GitHub 저장소 → Settings → Secrets and variables → Actions → **Variables** → `BEOLGEUM_SUPPORT_URL` 에 붙여 넣기.
3. main 에 아무 변경이나 push 되면 배포 때 켜진다 (Actions → beolgeum → Run workflow 도 가능).
- 허용 주소: `toss.me`, `qr.kakaopay.com`, `buymeacoffee.com`, `ko-fi.com` (그 밖의 주소는 무시 — 링크 바꿔치기 방지).
