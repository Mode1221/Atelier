# 출시 — 벌금장부

> Atelier `launch` 스킬로 작성. 사람이 할 일은 ⏳.

## L1. 사용성 테스트 계획 (D5 와 합침) ⏳
- 대상: 스터디·운동 모임 운영 경험자 5명 (개발자 지인 제외)
- 과제
  1. "다음 주부터 쓸 스터디 모임을 만들어 보세요. 지각 500원, 결석 2000원이에요."
  2. "멤버 3명을 넣고 오늘 모임을 기록해 보세요. 한 명은 지각, 한 명은 결석이에요."
  3. "결석한 사람이 2000원을 냈어요. 기록해 보세요."
  4. "멤버들에게 현황을 알려 주세요."
- 관찰 포인트: 관리 링크 저장 안내를 읽는가, 보기/관리 링크 차이를 이해하는가, 과제 미제출 체크를 찾는가
- 기록 표: 과제 / 성공·부분·실패 / 시간 / 막힌 지점 / 발언

## L2. 비공개 베타 ⏳
- 스터디 5~10개 모임, 2주. 지표: 2주 차에도 기록하는 모임 비율(중단 기준 20%), 오류율
- 피드백: 이메일 1곳, 첫 화면에 "의견 보내기" 링크 추가 예정

## L3. 랜딩
첫 화면 = 랜딩: 헤드라인(고유 가치 제안) → 바로 만들기 폼 → 대상 → 사용법 3단계 → FAQ. OG 이미지·설명 적용.
측정: `group_created`, `session_recorded`(활성화), `view_link_opened`(공유). UTM 은 로그 경로로 확인.

## L4. 채널·게시글 (초안, 게시는 사람)
| 채널 | 이유 | 형식 |
|---|---|---|
| 대학 커뮤니티 스터디 게시판 (에브리타임 등) | 스터디 운영자 밀집 | 홍보 게시판 규칙 확인 후 짧은 소개 |
| 오픈 카톡 스터디·러닝 모임방 | 대상 사용자 직접 | 방장 허락 후 |
| 디스콰이엇 | 메이커 피드백 | 제품 등록 + 제작기 |
| 스레드(Threads) | build in public | 과정 공유 |

**대학 커뮤니티용**
> 스터디 벌금 계산 귀찮으셨던 분들 위해 만들었어요.
> 출석·지각·결석만 체크하면 사람별 벌금이랑 미납액이 자동으로 쌓여요. 가입 없고 링크 하나로 단톡방에 공유돼요.
> 돈은 안 받고 계산만 해요. 써 보시고 불편한 점 알려 주시면 바로 고칠게요! → [링크]

**디스콰이엇 메이커 로그**
> 스터디 운영하면서 매주 엑셀로 지각비 계산하다가 만든 벌금장부입니다.
> - 가입 없음: 관리 링크 / 보기 링크 두 개로 권한을 나눴어요
> - 규칙이 바뀌어도 지난 회차는 그때 규칙으로 계산 (분쟁 방지)
> - Node 내장 SQLite + 서버 렌더링, 빌드 없는 구성
> 스터디·운동 모임 운영자분들의 피드백을 찾고 있어요.

예상 질문: "돈은?" → 계산만 / "개인정보?" → 별명 권장, 쿠키 없음 / "앱은?" → 모바일 웹으로 충분, 홈 화면 추가 가능

일정: D-7 베타 종료·수정 → D-day 대학 커뮤니티 1곳 집중 → D+1~3 나머지 채널 → D+7 회고
