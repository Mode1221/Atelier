# Changelog

## [0.1.0] - 미출시
### 추가
- 공개 베타: 베타 표시, "의견 보내기"(익명·연락처 자동 가림, 매일 GitHub 이슈로 수집), 수집 API
- 공유: 친구 모임에 알려주기·요약 공유·보기 링크 공유(휴대폰 공유 창), 보기 화면 "우리 모임 장부 만들기", 유입 경로(`?ref=`·utm) 기록
- 모임 만들기, 멤버, 회차 출결, 벌금 자동 계산, 납부 기록, 보기 링크, 카톡용 요약 복사
- 후원 링크(선택): `SUPPORT_URL` 설정 시 푸터에 "개발자 응원하기", `/support` 이동·클릭 기록
### 변경
- AI 대리 사용성 테스트 반영: 납부 기록을 회차 기록 바로 아래로, "납부 기록 (입금 확인)", 멤버 없을 때 "멤버 추가하러 가기", 멤버 영역 이름 "멤버 관리"
