# 예시 프로젝트 3종 실행 — 2026-10-01 (0.18.0 → 0.18.1)

0.16.0~0.18.0 보강이 실제 진행에서 뜨는지 확인했다. 빈 폴더 3개에서 플러그인을 붙인 별도 Claude Code 세션(`claude -p --plugin-dir`)으로 `/atelier-dev:pilot` 을 돌렸다.
- 자동 실행이라 대표 답변을 프롬프트에 미리 넣고, 범위는 1 아이디어 ~ 5 guard(build 는 로컬 최소 구현 + usertest 1회).
- 프롬프트에는 보강 항목(검수·광고 승인·AI 고지·세금)을 **언급하지 않았다** — 스킬이 스스로 그 항목에 닿는지 보기 위해.
- 외부 가입·배포·push 는 금지했다.

| A. 카카오 로그인 웹 (러닝 크루 출석) | "사람 할 일"에 서비스별 검수 제출물, usertest 가 가입 동선 캡처 | ✅ `docs/review/kakao/`(수집 사유 표·URL 목록·심사자 안내·콘솔 체크), usertest `shot` 으로 캡처 3장, 사람 할 일에 "검수 제출(출시 2주 전)". 이메일은 요청하지 않음(비즈 앱 불필요) |

## 고친 것 (0.18.1)
- 원인: 광고 승인 체크리스트가 grow R4(출시 뒤)와 build 참고 문서 깊은 곳에서만 연결돼 있었다. 출시 전 단계만 도는 진행에서는 닿지 않았다.
- guard G6 에 "광고 수익형이면 광고 네트워크 승인도 심사 — `ads-monetization.md` 체크리스트를 항목 그대로, 웹 검색 요약으로 대신하지 않는다"와 완료 조건 한 줄.
- idea I5 에 광고 수익 계산·승인 조건을 MVP 범위에 반영, 수익 경로가 있으면 세금 할 일(부업이면 겸업·건강보험)을 이 단계에서 알림.
