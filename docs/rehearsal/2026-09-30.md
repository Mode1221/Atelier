# 새 사용자 리허설 — 2026-09-30 (0.11.0 → 0.12.0)

빈 폴더에서 README → 설치 → `/atelier-dev:pilot` → 단계 문서를 **적힌 대로만** 따라가며, 도구를 실제로 실행했다.

| # | 발견 | 영향 | 조치 |
|---|---|---|---|
| 1 | 스킬 문서가 `<atelier>/skills/…` 로 도구를 부르는데 `<atelier>` 가 무엇인지 정의가 없음 | Claude 가 도구 위치를 추측해야 함 | pilot 머리에 경로 규칙 (스킬 Base directory 의 두 단계 위, 찾는 명령) |
| 2 | **사용자 프로젝트의 CI 에는 플러그인 폴더가 없어** 품질 게이트·사용성 테스트가 CI 에서 돌 수 없음. 예시는 Atelier 저장소 안(`../../skills`)이라 가려져 있었음 | 0.11.0 의 핵심 기능이 실제 사용자에게는 CI 에서 동작하지 않음 | `pilot/scripts/install-tools.mjs` — 도구 8개를 프로젝트 `scripts/atelier/` 에 복사(import 경로 변환, 출처·버전 머리말, `--check` 로 최신 여부), `npm run quality` 추가. 두 예시도 이 방식으로 전환, 복사본 = 원본을 테스트로 고정 |
| 3 | 복사한 도구가 사용자 린터에 걸림 (브라우저 코드 11건), 전부 제외하면 "쓰지 않은 제외" 경고 7건 | 사용자 CI 가 린트에서 실패 | 브라우저 코드가 든 파일(walk.mjs)만 린트 제외 |
| 4 | 복사한 도구 안의 설명 예시(`event: 'x'`)를 서비스 이벤트로 읽음 | 품질 게이트 오탐 | `scripts/atelier/` 는 검사 대상에서 제외 (`isTool`) |
| 5 | launch 문서의 상대 경로 오류 (`../../build/…`) | 참고 문서를 못 찾음 | `../build/…` |
| 6 | 세션 시작 안내가 "다음 할 일"로 앞 단계의 사람 대기 항목을 보여 줌 | 지금 할 일을 헷갈림 | 현재 단계 안의 첫 진짜 미완료 + 사람 대기 개수 + 증거 검사 결과를 세션 시작 때 표시 |

확인한 것 (문제 없음): 문서 간 단계 참조(`build B13` 등) 전부 존재 · 템플릿 → 디자인 도구 계획 → 증거 검사 연결 · 빈 프로젝트에서 품질 게이트가 해당 없는 검사를 건너뜀.
