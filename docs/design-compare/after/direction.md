# 방향 (D0) — 친구 여행 경비 정산 웹 · 도구형(Operate) · 절약 모드
- 쓰는 장면: 여행 마지막 밤 숙소, 친구 4명이 단톡방 링크를 각자 휴대폰으로 열어 "내가 누구한테 얼마 보내면 되지?"만 확인한다.
- 재료: 편의점 영수증(감열지·절취선), 송금 앱의 금액 입력 칸, 새벽 바다 안개.
- 색: 안개 #EEF1EE(바탕) · 종이 #FFFFFF(표면) · 잉크 #14212B(글자) · 흐린 잉크 #55636E · 송금 초록 #0B6E63(강조 하나) · 오류 #B3261E. 다크: #0F171C / #172229 / #E7EDEF / #9DAAB2 / #5CC3B4.
- 글꼴: Pretendard 하나, 금액은 고정폭 숫자(tabular-nums)·굵게.
- 레이아웃: 한 열, 왼쪽 정렬. 첫 화면의 주인공은 "보낼 돈" — 요약 숫자 카드 대신.
- 기억에 남을 한 가지: 송금 한 건 = 절취선이 있는 영수증 한 줄(금액 크게 + "금액 복사"). 나머지(지출 목록)는 카드 없이 조용한 목록.
- 피한 것(design-direction.md 3절): 영문 대문자 라벨, 똑같은 그림자 카드, 버튼 끝 "→", 파랑 기본값.
- 자체 검토 1회(절약): 메타 줄의 "A · B" 구분(3절 흔한 티)을 문장으로 바꿈 — "4명, 1인당 …", "민지님이 내고 4명이 나눔".
